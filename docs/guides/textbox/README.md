# Inside textBox

Owner-requested Italian HTML document for readers with no Web Component
background. `index.html` is the maintained standalone artifact: open it directly
in a browser, or serve the directory with a static host. No build or network
dependency is required for reading. External MDN links are optional references.

The 14 chapters distinguish educational fragments from actual Gramlot 0.1.5
implementation excerpts, document the current catalogue limitations and give
Python-first usage examples. This is documentation, not an executable Gramlot
demo or a new component implementation.

Verified on 2026-09-14: internal anchors, syntax of seven Python snippets,
actual builder acceptance of the example field/style declarations, browser
rendering and navigation with no document overflow at the observed 404px width.

Future revisions should recheck the implementation paths listed in chapter 14.
